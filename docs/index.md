# CCNA 200-301 Study Guide

This site holds only what I've actually gotten wrong (or guessed) on practice exams. If a topic isn't here, it means I haven't flagged it as a gap yet, not that it's unimportant.

## Workflow

1. Take a timed practice exam (Boson ExSim-Max).
2. For every missed question or confident-but-wrong guess, add an entry to [Still Missing](still-missing.md) and to the relevant domain page under `docs/domains/`.
3. Study only those entries. Skip anything I already know cold.
4. Once a topic is solid across two exams in a row, move it from "Still Missing" into the domain page's "Reviewed" section, or delete it.
5. Log each full practice exam attempt in the [Exam Log](exam-log.md) to track score trend and endurance.

## Exam domains

| Domain | Weight |

| 4. IP Services | 10% |

Study time should roughly track these weights, adjusted by how many gaps show up in each domain.
