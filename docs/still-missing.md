## Example: Stateful vs. stateless firewall behavior
- **Domain:** 5. Security Fundamentals
- **Source:** Domain 1.1 practice set, 2026-08
- **What I got wrong:** Mixed up which firewall type tracks connection state across packets.
- **Correct rule:** Stateful firewalls track the state of active connections (e.g., TCP handshake, session table) and allow return traffic automatically. Stateless firewalls evaluate each packet independently against static rules, with no memory of prior packets.
- **Status:** Reviewing
